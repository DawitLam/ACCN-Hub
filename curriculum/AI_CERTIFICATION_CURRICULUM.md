### AI Types Framework

**By Capability:**
- **Narrow AI (Weak AI):** Specific tasks (Siri, Netflix recommendations)
- **General AI (Strong AI):** Human-level intelligence (doesn't exist yet)
- **Super AI:** Surpasses human intelligence (theoretical)

## Session 2.1: The Machine Learning Pipeline (45 minutes)

### Learning Objectives
- Understand the ML workflow
- Learn about features, labels, and predictions
- Distinguish training from testing data

### Content Delivery

**🔗 Interactive Resources:**

   https://developers.google.com/machine-learning/glossary  
   *Reference guide for terminology*

2. **Visual Introduction to Machine Learning**  
   http://www.r2d3.us/visual-intro-to-machine-learning-part-1/  
   *Beautiful interactive visualization*

### The ML Pipeline Explained

```
DATA COLLECTION → DATA PREPARATION → MODEL TRAINING → 
MODEL EVALUATION → PREDICTION → DEPLOYMENT
```

**Key Concepts:**

**Features (Input):**
- Data attributes used for predictions
- Example: For house prices → square footage, bedrooms, location

**Labels (Output):**
- What we're trying to predict
- Example: House price = $350,000

**Training:**
- Model learns patterns from historical data
- Uses 70-80% of dataset

**Testing:**
- Evaluate model on unseen data
- Uses 20-30% of dataset

**Prediction:**
- Apply trained model to new data

### Paper Machine Learning Exercise (20 minutes)

**Activity: "Teach a Paper Model"**

**Materials Provided:**
- Worksheet with 20 geometric shapes
- Features: color (red/blue), sides (3/4/5), size (small/large)
- Labels: circle/square/triangle

**Instructions:**
1. **Training Phase:** Use first 15 shapes to learn patterns
2. **Testing Phase:** Predict labels for last 5 shapes
3. **Evaluation:** Calculate accuracy

**Debrief:**
- What patterns did you notice?
- Which features were most helpful?
- Did you make mistakes? Why?
- This is what ML models do, but with numbers!

   http://cs229.stanford.edu/

2. **"Types of Machine Learning"** - ML Mastery  
   https://machinelearningmastery.com/types-of-learning-in-machine-learning/

### Learning Paradigm Framework

**1. Supervised Learning** (Has labeled data)
- **Classification:** Categorize (spam/not spam)
- **Regression:** Predict numbers (house prices)
- *Example: Email spam filter*

**2. Unsupervised Learning** (No labels)
- **Clustering:** Group similar items
- **Anomaly Detection:** Find outliers
- *Example: Customer segmentation*

**3. Reinforcement Learning** (Learn from rewards)
- Agent takes actions
- Environment provides feedback
- *Example: Game-playing AI*

**4. Transfer Learning** (Reuse knowledge)
- Start with pre-trained model
- Fine-tune for your task
- *Example: Teachable Machine uses this!*

### Data Quality Framework

**The 3 V's of Quality Data:**

**1. Volume**
- Need enough examples
- Rule of thumb: 1000+ samples per category
- More data often beats better algorithms

**2. Variety**
- Diverse representation
- Multiple scenarios covered
- Avoid sampling bias

**3. Veracity**
- Accurate and truthful
- Properly labeled
- No errors or corruption

### Real-World Data Problems

**Problem 1: Bias**
- Training data doesn't represent everyone
- Example: Facial recognition fails for darker skin tones

**Problem 2: Incompleteness**
- Missing values in dataset
- Can't make predictions without data

**Problem 3: Noise**
- Errors in data
- Incorrect labels
- Outliers that confuse model

**Problem 4: Privacy**
- Collecting data ethically
- Consent and anonymization
- Legal requirements (GDPR, CCPA)
