### The ML Pipeline Explained

```
DATA COLLECTION → DATA PREPARATION → MODEL TRAINING → 
MODEL EVALUATION → PREDICTION → DEPLOYMENT
```

**Key Concepts:**

**Features (Input):**
- Data attributes used for predictions
- Example: For house prices → square footage, bedrooms, location

**Labels (Output):**
- What we're trying to predict
- Example: House price = $350,000

**Training:**
- Model learns patterns from historical data
- Uses 70-80% of dataset

**Testing:**
- Evaluate model on unseen data
- Uses 20-30% of dataset

**Prediction:**
- Apply trained model to new data

### Learning Paradigm Framework

**1. Supervised Learning** (Has labeled data)
- **Classification:** Categorize (spam/not spam)
- **Regression:** Predict numbers (house prices)
- *Example: Email spam filter*

**2. Unsupervised Learning** (No labels)
- **Clustering:** Group similar items
- **Anomaly Detection:** Find outliers
- *Example: Customer segmentation*

**3. Reinforcement Learning** (Learn from rewards)
- Agent takes actions
- Environment provides feedback
- *Example: Game-playing AI*

**4. Transfer Learning** (Reuse knowledge)
- Start with pre-trained model
- Fine-tune for your task
- *Example: Teachable Machine uses this!*

### Data Quality Framework

**The 3 V's of Quality Data:**

**1. Volume**
- Need enough examples
- Rule of thumb: 1000+ samples per category
- More data often beats better algorithms

**2. Variety**
- Diverse representation
- Multiple scenarios covered
- Avoid sampling bias

**3. Veracity**
- Accurate and truthful
- Properly labeled
- No errors or corruption

### Real-World Data Problems

**Problem 1: Bias**
- Training data doesn't represent everyone
- Example: Facial recognition fails for darker skin tones

**Problem 2: Incompleteness**
- Missing values in dataset
- Can't make predictions without data

**Problem 3: Noise**
- Errors in data
- Incorrect labels
- Outliers that confuse model

**Problem 4: Privacy**
- Collecting data ethically
- Consent and anonymization
- Legal requirements (GDPR, CCPA)

### Key Ethical Issues in AI

**1. Bias and Fairness**
- **Problem:** AI inherits human biases from training data
- **Examples:**
  - Hiring algorithms favoring men
  - Facial recognition failing on darker skin
  - Loan approval discrimination
- **Solution:** Diverse datasets, bias testing, human oversight

**2. Privacy**
- **Problem:** AI needs data, but at what cost?
- **Examples:**
  - Social media tracking
  - Surveillance systems
  - Personal data collection
- **Solution:** Data minimization, consent, anonymization

**3. Transparency (Explainability)**
- **Problem:** "Black box" AI - can't explain decisions
- **Examples:**
  - Medical diagnosis AI
  - Criminal sentencing algorithms
  - Loan denials
- **Solution:** Explainable AI (XAI), model documentation

**4. Accountability**
- **Problem:** Who's responsible when AI fails?
- **Examples:**
  - Self-driving car accidents
  - AI-generated misinformation
  - Automated trading crashes
- **Solution:** Clear regulations, human-in-the-loop

**5. Job Displacement**
- **Problem:** AI automation replacing workers
- **Examples:**
  - Manufacturing robots
  - Customer service chatbots
  - Automated content creation
- **Solution:** Reskilling programs, AI augmentation vs replacement

**6. Dual Use (AI Weapons)**
- **Problem:** AI for good or harm?
- **Examples:**
  - Autonomous weapons
  - Deepfakes
  - Surveillance states
- **Solution:** International regulations, ethical guidelines

### Hands-On Activity: Build a Batch Predictor (30 min)

**Challenge:** Process multiple images at once

```python
import os
import glob

def batch_predict(model_path, image_folder, class_names):
    """Predict on all images in a folder"""
    
    # Load model
    model = tf.keras.models.load_model(model_path)
    
    # Get all images
    image_files = glob.glob(f"{image_folder}/*.jpg")
    
    results = []
    
    for img_path in image_files:
        # Load and predict
        img = Image.open(img_path).resize((224, 224))
        img_array = np.array(img) / 255.0
        img_array = np.expand_dims(img_array, 0)
        
        predictions = model.predict(img_array, verbose=0)
        
        predicted_class = class_names[np.argmax(predictions)]
        confidence = np.max(predictions) * 100
        
        results.append({
            'file': os.path.basename(img_path),
            'prediction': predicted_class,
            'confidence': confidence
        })
    
    return results

# Use it
results = batch_predict('my_model.h5', 'test_images/', 
                       ['Rock', 'Paper', 'Scissors', 'Nothing'])

# Show results
for r in results:
    print(f"{r['file']}: {r['prediction']} ({r['confidence']:.1f}%)")
```

**Understanding Metrics:**
```
Confusion Matrix:
                Predicted
              Fail  Pass
Actual Fail   [[40,   10]     True Negative, False Positive
      Pass    [ 5,   45]]    False Negative, True Positive

Accuracy = (TP + TN) / Total = (45 + 40) / 100 = 85%

Precision = TP / (TP + FP) = 45 / (45 + 10) = 81.8%
"Of those predicted to pass, 81.8% actually passed"

Recall = TP / (TP + FN) = 45 / (45 + 5) = 90%
"Of those who passed, we correctly identified 90%"

F1-Score = 2 * (Precision * Recall) / (Precision + Recall) = 85.7%
"Balanced measure"
```

```python
model = RandomForestClassifier(n_estimators=100, random_state=42)

scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')

print("Cross-validation scores:", scores)
print(f"Average: {scores.mean():.2%} (+/- {scores.std():.2%})")

# Visualize
plt.plot(range(1, 6), scores, marker='o')
plt.axhline(y=scores.mean(), color='r', linestyle='--', label='Mean')
plt.xlabel('Fold')
plt.ylabel('Accuracy')
plt.title('Cross-Validation Scores')
plt.legend()
plt.grid(True)
plt.show()
```

**How it Works:**
```
Dataset split into 5 folds:

Iteration 1: [Test][Train][Train][Train][Train]
Iteration 2: [Train][Test][Train][Train][Train]
Iteration 3: [Train][Train][Test][Train][Train]
Iteration 4: [Train][Train][Train][Test][Train]
Iteration 5: [Train][Train][Train][Train][Test]

Average all 5 test scores = Final performance estimate
```

**How a Neuron Works:**
```python
def artificial_neuron(inputs, weights, bias):
    """
    1. Multiply inputs by weights
    2. Sum everything + bias
    3. Apply activation function
    """
    # Weighted sum
    z = sum(inputs[i] * weights[i] for i in range(len(inputs))) + bias
    
    # Activation (ReLU example)
    output = max(0, z)  # ReLU: returns z if positive, else 0
    
    return output

# Example
inputs = [2, 3, 4]
weights = [0.5, 0.3, 0.2]
bias = 1.0

output = artificial_neuron(inputs, weights, bias)
print(f"Neuron output: {output}")
```

**Activation Functions:**
```python
import numpy as np
import matplotlib.pyplot as plt

def relu(x):
    """Rectified Linear Unit - most common"""
    return np.maximum(0, x)

def sigmoid(x):
    """Sigmoid - outputs between 0 and 1"""
    return 1 / (1 + np.exp(-x))

def tanh(x):
    """Tanh - outputs between -1 and 1"""
    return np.tanh(x)
```

## Session 8.3: Convolutional Neural Networks (CNNs) (45 minutes)

### Learning Objectives

### Why CNNs for Images?

**Problem with Fully Connected:**
```python
# Fully connected layer for 28x28 image
# 784 inputs × 128 neurons = 100,480 parameters
# Just for ONE layer!

# For larger images (224x224 color):
# 224 × 224 × 3 = 150,528 inputs
# 150,528 × 128 = 19,267,584 parameters!
# Too many! Slow and prone to overfitting
```

**CNN Solution:**
```python
# Convolutional layers learn local patterns
# Shared weights = fewer parameters
# Better for images!
```

**CNN Architecture:**
```
Input Image (28×28)
    ↓
Convolution Layer (learn features like edges)
    ↓
Pooling Layer (reduce size)
    ↓
Convolution Layer (learn complex patterns)
    ↓
Pooling Layer
    ↓
Flatten
    ↓
Dense Layer
    ↓
Output (10 classes)
```

### Build a CNN for MNIST

```python
# Create CNN model
```

```python
def make_prediction(input_data, explain=True):
    """

    model = joblib.load('final_model.pkl')

    prediction = model.predict([input_data])[0]
```

### Required Platform Features:

- Auto-graded quizzes (multiple choice, code submission)
- Discussion forums (threaded conversations)
- File submission (Jupyter notebooks, PDFs)
- Progress tracking (completion percentages)
- Certificate generation (PDF with verification)
- Code execution environment (Jupyter integration)
- Peer review system (for projects)

### Recommended Tools:
- **Video:** YouTube (free) or Vimeo (better player control)
- **Code:** Google Colab (free GPU, no local setup)
- **Notebooks:** Embedded Colab links with auto-save to Drive
- **Datasets:** Kaggle + Google Drive links for easy access
- **Communication:** Discord for real-time help, email for official
- **Code Submission:** GitHub Classroom integration
- **Quizzes:** Built-in LMS quiz engine with randomization

### Content Organization:
Each day module contains:
1. **Pre-class preparation checklist** (5-10 min)
2. **Video lectures** (embedded, timestamped)
3. **Reading materials** (web links + PDF backups)
4. **Interactive activities** (live or recorded)
5. **Hands-on labs** (Google Colab notebooks)
6. **Knowledge checks** (auto-graded quizzes)
7. **Homework assignments** (project-based)
8. **Discussion prompts** (forum engagement)
9. **Office hours** (optional Q&A sessions)

### Assessment Structure:
- **Daily Quizzes:** 10-15 questions, unlimited attempts
- **Homework:** Graded on completion + quality rubric
- **Mid-program Check:** Day 5 comprehensive quiz
- **Final Project:** 100-point rubric (see Day 10)
- **Participation:** Forum posts, peer reviews, attendance

### Grading Breakdown:
- Daily Quizzes: 30%
- Homework Projects: 30%
- Final Project: 30%
- Participation: 10%

**Total: 100%**
